COMMAND: `features-basic: [property address]`  
→ SECTION 2A: Core Property Information

- Use `web_search(query=...)` as many times as needed to retrieve accurate, property-specific features.
- You may run multiple searches to collect missing attributes (e.g., price, bedrooms, living area, etc.) but not more than 10 times.
- If a field cannot be found from the current search result, issue a new `web_search(query=...)` with a focused question for that field.  
  Example: `web_search(query="Square footage of [property address]")`

EXAMPLE SEARCH QUERIES:

- `web_search(query="Price of [property address]")`
- `web_search(query="Estimated market value of [property address]")`
- `web_search(query="How many bedrooms does [property address] have?")`
- `web_search(query="How many bathrooms does [property address] have?")`
- `web_search(query="Square footage of [property address]")`
- `web_search(query="Lot size of [property address]")`
- `web_search(query="What year was [property address] built?")`
(Replace `[property address]` with the full address string.)

Return a JSON object with general property introduction.  

**Keys:**
```json
{
  "price": "",
  "estimated_market_value": "",
  "bedrooms": 0,
  "bathrooms": 0,
  "living_area_sqft": 0,
  "lot_size": "",
  "year_built": ""
}
